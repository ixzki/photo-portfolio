# 示例内容

这些文件用于展示网站能力，不含真实足迹或站点拥有者的照片、联系方式、行程记录。示例照片来自 Unsplash，图像与合成路线没有地理对应关系，不代表站点作者拥有这些摄影作品。

## 内容入口

| 内容 | 文件 | 用途 |
| --- | --- | --- |
| 4 组示例作品、首页精选和网站信息 | `src/lib/data.ts` | 建筑、城市、自然与肖像版式；网站名 Portfolio，邮箱 hello@example.com |
| 示例旅行正文和几何 | `src/data/example-journey.json` | 2 段线路、49 个合成点、9 处正文、5 个精选点位 |
| 示例封面与旅行标识 | `src/lib/travel-seed.mjs` | 示例网址 `example-journey`，Unsplash 封面 |
| [示例 CSV](./example-journey.csv) | `examples/example-journey.csv` | 自动识别时间、解析轨迹与海拔、首屏统计验证 |

路线坐标是人为设计的折线，坐标之间插值得到中间点；时间和海拔按示例规则生成，没有复制、抽样或改写任何人的实际足迹。折线仅用于展示地图交互，不代表道路或可行驶线路，不能用于导航。

示例使用北京时间 `2024-05-01 08:00` 至 `2024-05-02 10:50`，中间留有过夜断段，并包含一次同一坐标的再次停靠。正文同时展示点位、线路段、Markdown 段落、引用、列表和横竖照片。

## 查看与导入

1. 执行 `npm ci`，再执行 `npm run demo`。
2. 打开 [本地示例首页](http://127.0.0.1:3200) 或 [示例旅行](http://127.0.0.1:3200/travel/example-journey)。该模式不连接数据库，始终只读。
3. 若要练习后台编辑，连接自己的独立开发数据库并打开“新建旅行”，选择本目录的 CSV。使用默认断段设置与 100 米精度筛选，会得到与示例相同的 49 点、2 段轨迹。
4. CSV 只含轨迹记录，不自动生成游记和照片；应用轨迹后自行添加点位或路段正文。需要连同示例正文初始化时，可显式运行 `node scripts/migrate-travel.mjs --seed-example`。

示例启动器使用端口 3200 和独立 `.next-demo/` 目录，可与端口 3100 的日常预览共存。`npm run demo -- build` / `npm run demo -- start` 用于示例的生产构建检查。不要把示例启动命令作为 Vercel 的构建命令。

## 换成自己的内容

已连接数据库的站点使用后台管理作品、旅行和设置；修改仓库示例不会覆盖已有数据库内容。上传自己的照片到图床，在部署环境配置对应域名后，在后台填写图片链接。真实足迹 CSV 保存在仓库外，仅在后台选取需要的时间范围。

公开提交前检查新加入 `examples/` 的文件确实为合成示例。生产数据库、凭据和图床文件由部署者单独管理，Git 历史不属于示例模式的隔离范围。

# 后台界面规范

后台公共样式集中在 `src/app/admin/admin.css`，由后台布局引入；作品、旅行及内容表单只在 CSS Module 中保留各自的编辑布局。公共前台不使用后台样式。

- 延续网站的 Jost / Noto Sans SC 字体、黑白主色和直角控件。背景为浅灰，编辑内容为白色，细灰线区分分区。红色只用于删除和错误提示。
- 页面使用同一标题栏，主按钮为黑底白字，次要按钮为白底细边框。正文默认 14px，字段名称 13px，说明和状态 12px；不添加装饰性副标题。
- 桌面侧栏显示当前栏目，深层编辑页仍选中所属栏目。760px 以下采用可横向滚动的导航，并自动使当前栏目可见。
- 表单按任务分区；封面、CSV、尺寸和更多设置等内容可折叠。旅行编辑把地图和正文分栏，窄屏改为上下排列。
- 保存操作位于底部吸附栏，并显示保存状态。删除旅行放在“更多设置”中，原有确认流程保留。媒体信息沿用离开输入框时自动保存，并显示该行为说明。
- 表格在窄屏内横向滚动，不撑宽整页。手机表单改为单列；预览环境提示不遮挡保存栏。

后台总览涵盖作品、旅行、精选和媒体数量，以及作品和旅行入口。媒体库以浏览图片为主，添加表单默认收起，支持按标题和图片描述搜索。

界面调整不改变 CSV 解析、路线计算、正文、图片排版或保存的数据结构；使用现有后台账号与数据库，无须迁移。

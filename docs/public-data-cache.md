# 公开数据缓存

当前项目未启用 Next.js Cache Components，使用 Next.js 16.3.4 仍支持的 `unstable_cache` 为公开数据库读取增加跨请求的 Data Cache。外层 React `cache` 继续合并同一服务端渲染中的重复读取。

## 缓存范围

| 数据 | 缓存方式 | 默认周期 |
| --- | --- | --- |
| 导航、页脚、网站元数据所用的 `getShellSettings` | 独立公开设置条目 | 300 秒 |
| 已发布旅行 slug 列表 | 小型索引条目 | 300 秒 |
| 单条已发布旅行详情 | 按 slug 独立条目 | 300 秒 |
| 总览路线几何 | 按 slug 独立条目 | 300 秒 |
| `/travel` 与 `/travel/[slug]` | 路由 `revalidate = 300`；详情返回空 `generateStaticParams`，首次访问后按需生成并缓存页面 | 300 秒 |
| 后台旅行与设置 API | 不使用公开缓存，`Cache-Control: private, no-store` | 不缓存 |

公开总览入口为 `getPublishedJourneyOverviews`，返回的每条路线仅包含 `slug`、`shade`、`title`、`segments`。数据库查询同样只选这些字段，正文、封面、照片、逐点时间及海拔不再随总览传输；详情页继续获得完整数据。

后台旅行 API 新建、修改、重命名、发布/取消发布、删除成功后，立即调用 `revalidateTag(tag, { expire: 0 })`，并使总览及所有旅行详情路由失效。网站设置保存后同样立即失效设置 tag 和根布局。Route Handler 不使用仅适用于 Server Action 的 `updateTag`，也不使用会先返回旧内容的 `"max"` 失效方式。下一次服务端读取会等待新数据；已打开的其他浏览器页面仍需重新导航或刷新，不会被服务端主动推送更新。

自动周期过期遵循 Next 的重新验证机制；后台保存有显式立即失效，因此不必等待 300 秒。手动 SQL 或外部同步脚本绕过后台 API 时不会主动触发失效，应等待重新验证或重新部署；不能把这些外部写入视为即时发布。

## 环境隔离与体积

缓存键及 tag 含运行环境、数据来源和数据库连接配置的 SHA-256 摘要。开发、Vercel preview、生产和显式示例模式各自隔离；连接串、密码及数据库域名不会作为明文缓存键或日志输出。摘要仅用于隔离，不作为凭据。

Next 内置 Data Cache 的单条目上限为 2 MiB，旅行上传上限则为 3,500,000 字节。因此在服务端先将每个条目 gzip 后编码为 base64，读取时无损还原，客户端协议不变。安全阈值为编码后 1,500,000 字节，预留框架 JSON 包装空间。极端大且不可压缩的合法内容直接返回本次已读数据、不写缓存、不重复查询，避免超限导致页面报错。数据库错误继续抛出，不会缓存异常或用示例内容掩盖连接故障。

2026-09-15 开发数据库只读测量：

| 路线 | 原详情 JSON | 总览 JSON | 详情缓存编码 | 总览缓存编码 |
| --- | ---: | ---: | ---: | ---: |
| northwest-2025 | 1,238,229 B | 468,785 B | 338,372 B | 200,944 B |
| yili-2026 | 1,160,475 B | 439,348 B | 322,124 B | 185,636 B |

两条路线总览的数据由约 2.40 MB 减到 0.91 MB，减少约 62%。这些是 JSON 数据体积，实际页面响应还包含框架、布局及资源引用；缓存编码是服务端存储大小，并非网络传输体积。

## 验证

- `node --test test/public-cache-policy.test.mjs` 检查来源隔离、敏感信息不进入键、Unicode/坐标/时间海拔及不存在数据的无损往返、大型路线压缩、不可压缩数据安全回退、损坏条目不伪造示例数据。
- 本地预览用独立临时旅行检查：不存在页缓存后新建、正文更新、重命名、取消发布、重新发布、删除均在操作后的第一次公开请求返回新状态；总览未包含正文；后台响应保持 `private, no-store`。临时旅行已删除，原有旅行未修改。
- 此次本地集成检查不等同于已部署 Vercel。正式站的缓存命中和响应时间应在部署后另行验证。
- `next build` 通过后，在本机 `next start` 重复了上述创建到删除的检查，并确认首页、旅行总览和旅行详情的重复请求返回 `x-nextjs-cache: HIT`。单次西北环线详情样本首次生成 1,679ms、缓存命中 26ms；这是本机完整响应耗时，不是正式站速度对比或页面全部图片加载时间。

# 页面加载动画

视觉参考 [archsource](https://www.archsource.cn/) 的白底描边字标：使用本站 Jost 字体和后台配置的网站名称，黑色缓慢填入字形；首屏就绪后填满并淡出白色遮层。不显示副标题或虚构进度百分比，也不增加动画库依赖。只有示例数据使用 `Portfolio`，加载组件没有内置示例名称。

## 出现时机

- 直接打开任意前台页面时显示，后台和 `/setup` 不显示。
- 点击导航进入旅行总览、点击地图路线进入详情、前进或后退到旅行页面时显示。
- 同页点击、链接预取、另开标签页不会触发当前页遮层；中途切换到其他页面会取消原加载状态。

根布局先读取共用的 `getShellSettings`，将同一份网站名称直接传入加载组件和导航，页脚也使用这份设置。首个 HTML 中的字标即为实际站名，不通过导航的客户端 effect 再替换，也不使用含示例站名的 Suspense 占位。该读取继续复用 5 分钟公开缓存及请求内去重；未命中时需先取得站点设置，页面内容仍使用各自的加载占位。

## 退出条件

- 等待当前目标页面替换掉路由 loading 占位、字体加载完成，以及首张主图加载结束（成功或失败）。不等待正文内所有照片。
- 旅行总览额外等待地图完成初始化并收到首张底图，或底图请求全部结束。失败的底图不会让加载层一直停留。
- 首次最短展示 350ms，从页面导航开始计时；旅行页面切换最短展示 180ms。加载已经花掉的时间计入最短展示时间。
- 最长等待 6 秒后退场；初始 JavaScript 加载失败时，CSS 最迟在 6.4 秒释放遮层。无 JavaScript 时通过 `noscript` 直接隐藏，内容或错误提示仍可见。
- 开启 `prefers-reduced-motion` 后取消字形填充动画和最短停留，只做短暂淡出。

加载层是全屏固定定位，不占据文档空间；移除后恢复页面原有的顶部滚动进度条。

## 验证边界

- 检查首页、旅行总览和旅行详情的原始 HTML：两个字标图层及导航应使用同一个配置名称，在 JavaScript 执行前即正确。
- 分别使用数据库模式和独立示例模式验证，避免示例名称进入已有站点的加载层。
- 在浏览器慢速网络下检查首帧、进入旅行、后退、完成后退场及减少动态效果；恢复临时网络和视口设置。
- 正式网络表现需部署后测量。本地检查不能替代线上验证。

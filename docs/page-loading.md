# 页面加载动画

视觉参考 [archsource](https://www.archsource.cn/) 的白底描边字标：使用本站 Jost 字体和当前网站名称（默认 `iXzKi`），黑色缓慢填入字形；首屏就绪后填满并淡出白色遮层。不显示副标题或虚构进度百分比，也不增加动画库依赖。

## 出现时机

- 直接打开任意前台页面时显示，后台和 `/setup` 不显示。
- 点击导航进入旅行总览、点击地图路线进入详情、前进或后退到旅行页面时显示。
- 同页点击、链接预取、另开标签页不会触发当前页遮层；中途切换到其他页面会取消原加载状态。

根布局不等待数据库设置读取再输出页面：导航和页脚通过独立 Suspense 边界加载，字标及主内容占位可先随 HTML 输出。

## 退出条件

- 等待当前目标页面替换掉路由 loading 占位、字体加载完成，以及首张主图加载结束（成功或失败）。不等待正文内所有照片。
- 旅行总览额外等待地图完成初始化并收到首张底图，或底图请求全部结束。失败的底图不会让加载层一直停留。
- 首次最短展示 350ms，从页面导航开始计时；旅行页面切换最短展示 180ms。加载已经花掉的时间计入最短展示时间。
- 最长等待 6 秒后退场；初始 JavaScript 加载失败时，CSS 最迟在 6.4 秒释放遮层。无 JavaScript 时通过 `noscript` 直接隐藏，内容或错误提示仍可见。
- 开启 `prefers-reduced-motion` 后取消字形填充动画和最短停留，只做短暂淡出。

加载层是全屏固定定位，不占据文档空间；移除后恢复页面原有的顶部滚动进度条。

## 验证边界

本地验证包含首页及旅行切换的慢速网络动画、390px 视口布局、减少动态效果、点击路线进入详情、后退到总览，以及加载完成后移除遮层。临时阻断 OpenStreetMap 底图请求时，24 张底图加载失败，页面仍释放遮层并保留路线及底图失败提示。所有浏览器网络与媒体模拟均已恢复。

缓存的生产构建验证使用本机 `next start` 和独立 Neon 开发分支，不代表已发布到 Vercel；正式网络表现需部署后测量。

# 自驾轨迹与游记

`/travel` 是导航下方直到屏幕底部的整屏路线总览，旅行总览和详情均隐藏站点页脚，灰色底图叠加所有已整理路线。每条路线在 `src/lib/journeys.ts` 注册独立 `slug`、灰色 `shade` 和 `cover` 封面信息，点击轨迹进入 `/travel/[slug]`，地图上不显示路线标题。轨迹可通过 Tab 聚焦、Enter 进入，保留屏幕阅读器名称；路线有 22px 点击范围，悬停或聚焦时变黑。当前只有已整理的新疆路线，不添加虚构旅行。

`/travel/xinjiang-2026` 首屏复用作品详情的整屏大图、透明导航、右下角黑底白字标题和滚动显隐动效。使用现有“六月伊犁”封面（`https://img.ixzki.com/2026/07/01/28a0242a4ed34652af813c010bd9a23c.jpg`，6000 × 4500），来源为站内作品 `work-mr1uh10v`。标题上方绘制不带底图、地点标签或副标题的完整白色路线轮廓，保留 8 个记录段，使用 Mercator 比例投影并仅删去低于 0.6px 的重复细节。桌面和手机首屏均填满视口。

下滑进入正文后才显示左上方随行地图：电脑端（1024px 及以上）地图放大至最大 600 × 452px 地图画面，手机自适应约 156 × 158px；地图层不透明度 60%，四边渐隐羽化，中央定位黑点保持清晰。地图署名独立置于羽化区域之外。桌面正文从地图右侧铺满至站点右边距，取消正文及段落最大宽度限制；手机正文保持全宽，并将阅读位置安排在小地图下方。沿用站点 Jost / Noto Sans SC、边距和黑白配色，不增加副标题。详情页不显示独立返回箭头，可通过顶部“旅行”导航返回总览。

正文滚动时，以视口上方 20% 的阅读位置计算相邻地点间的进度，黑色线条沿实际轨迹逐步延伸；上滚时回退，当前地点同步高亮。地图视角每次滚动均跟随轨迹前端的插值位置，中央黑点始终固定；不再由地点切换触发平移。拖动、双击和手势缩放关闭，地图上的滚动交给正文；加减按钮只改变缩放比例，保持当前点居中。每个地点的 `routePointIndex` 指向按时间排列的轨迹点；新疆锚点从原始采样时间匹配，松树头两次停留对应不同轨迹位置。按段内距离插值，不跨定位断点补线。地图生命周期与滚动进度分离，已画完的路段不随每帧重复绘制；图片加载改变正文高度时重新测量。终点完成轨迹绘制；完整行程范围在总览查看，详情始终跟随当前点。尊重系统减少动态效果设置。

## 接入

1. 将原始 CSV 放在项目外或已忽略的 `.local-preview/`，核实坐标系、列名、Unix/ISO 时间格式。
2. 仅选取本次旅行区间运行转换器，例如：

   `python -X utf8 scripts/import-travel-csv.py "本机文件.csv" --title "旅行标题" --from-date "2024-02-28T00:00:00+08:00" --to-date "2024-02-29T00:00:00+08:00" --crs wgs84`

3. 导入器默认写入 `.local-preview/travel-import.json`，不直接发布轨迹，不覆盖已有图文。按时间排序，保留采样轨迹；默认大于一小时或五公里的相邻采样点断开，不自动补齐道路，也不据此推断驾驶方式。实际数据采样间隔确定后可调整两个阈值。
4. 核对区间和轨迹后，将结果填入 `src/data/travel.json`，加入 `stops`。每个地点提供唯一 `id`、`title`、WGS84 `position: [纬度, 经度]`、按时间匹配的 `routePointIndex`、`paragraphs` 字符串数组、`images` 数组（`src/alt/width/height`），按游记顺序排列。图片使用 `https://img.ixzki.com/...`。

前台读取这一份经过挑选的数据，Vercel 随代码部署，不访问原始 CSV，不依赖服务器可写文件系统；Neon 现有内容不变。若后续需要后台编辑，可将相同数据结构接到 Neon。

# 前台页面视觉与交互规律

核对日期：2026-09-11。依据当前代码和本地首页、作品、作品详情、关于页的实际渲染。范围为访客前台，后台表单样式不作为旅行页参照。

后续调整：照片书功能已按用户要求移除，旅行页暂留空白。以下保留网站通用视觉规律，供后续开发参考。

| 维度 | 当前网站规律 |
| --- | --- |
| 配色 | `--back-color: #fff`、`--fore-color: #000`；图片占位 `#f0f0f0`。照片提供主要色彩。 |
| 字体 | 根布局加载 Jost（英文）、Noto Sans SC（中文），全站继承同一字体栈。导航实际字重 700，正文 400；作品标题常态被 `.hover-invert` 统一为 400，悬停为 700。 |
| 字号 | 主字号 `calc(13px + 0.6vw)`；作品标题 `calc(14px + 0.45vw)`；副标题为主字号的 0.8 倍；420px 以下主字号 15px。 |
| 边距 | `--edge-gap: calc(8px + 1vw)` 控制作品网格间距、作品和关于页的外边距。内容紧接导航。 |
| UI 形态 | 摄影优先、直角图片、无前台卡片阴影或装饰渐变；文字承担说明。标题和导航选中态为黑底白字。 |
| 悬停 | `.hover-invert` 用 0.28s ease 反转背景和文字色，并加粗；首页和作品缩略图用 0.5s ease 放大到 1.02。 |
| 图片加载 | `ImageLoader` 从 3px 模糊、0.72 透明度过渡到清晰，耗时 0.5s。 |
| 入场 | 首页横屏右侧 40vw 滑入、竖屏下方 18vh 滑入；作品列表从下方 500px 淡入。均为 0.5s，缓动 `cubic-bezier(0.22, 1, 0.36, 1)`。 |
| 详情动效 | 封面 0.85s 淡入/位移；图片进入视区后以 0.58s 透明度和 0.72s 位移显现；标题随滚动方向隐藏/出现。 |
| 响应式 | 横竖屏切换布局：作品四列/两列、关于左右/上下排版；导航保持固定。横屏版权固定，竖屏进入文档流。 |
| 减少动画 | 全局 `prefers-reduced-motion: reduce` 禁用动画与过渡。 |

代码依据：`src/app/globals.css`（包含后置覆盖规则）、`src/app/layout.tsx`、`src/components/WorksGrid.tsx`、`FeatureStrip.tsx`、`AboutPageClient.tsx`、`DetailMotionTrigger.tsx`、`DetailImageFrame.tsx`、`DetailProjectTitle.tsx`。
